# PRDs — VIGIL

Product Requirements Documents for VIGIL's feature initiatives, generated and kept
up to date by the `prd-writer` subagent (`.claude/agents/prd-writer.md`) via the
`prd-generator` skill.

Each file below documents one feature or product initiative: problem statement,
goals and success metrics, scope, users, user stories, functional and non-functional
requirements, and open questions/assumptions. The `.md` file is the source of truth;
a mirrored `.docx` of the same name is regenerated alongside it on every update — see
each file's `## Change Log` section for its revision history.
