# User Stories — VIGIL

Dev-ready user story documentation for VIGIL's user-facing features and flows,
generated and kept up to date by the `user-story-writer` subagent
(`.claude/agents/user-story-writer.md`) via the `user-story-creator` skill.

Each file below documents one feature or workflow: actors, epics, stories with
functional requirements and acceptance criteria, out-of-scope items, and open
questions. Files are updated in place as the corresponding feature evolves —
see each file's `## Change Log` section for its revision history.
